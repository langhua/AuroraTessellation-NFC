# WS2812B-5050 4×4 矩阵测试（ESP32-S3-DevKitC-1）

验证 4×4（16 颗）WS2812B 矩阵模块的最小点亮 + 灯序。

## 模块引脚（库内 `WS2812B-5050-4x4`）

```
         顶排
   GND | VCC | DOUT | GND
   ─────────────────────
        （30×30mm 板）
   ─────────────────────
   GND | VCC | DIN  | GND
         底排
```

- 底排：pin1=GND, pin2=VCC, pin3=DIN, pin4=GND
- 顶排：pin1=GND, pin2=VCC, pin3=DOUT, pin4=GND
- 灯序：**每列从下往上爬**（列与列之间在底部相连），像素 0（=元件 LED 1）在**右下角**。✅ 已实测验证。

  ```
        列0  列1  列2  列3
  第0行: 15   11    7    3
  第1行: 14   10    6    2
  第2行: 13    9    5    1
  第3行: 12    8    4    0   ← 像素0在右下角
  ```

## 接线

| ESP32-S3-DevKitC-1 | 4×4 模块 | 说明 |
|---|---|---|
| `3V3`（或外接 5V） | `VCC` | 电源 |
| `GPIO15`（丝印 `15`） | `DIN` | 数据输入 |
| `GND` | `GND` | 共地 |
| — | `DOUT` | 空接或级联 |

> ⚠️ **电源**：16 颗满白约 960mA。用 3V3 供电必须保持低亮度（固件默认 30，安全）。满亮度请外接 5V 到模块 VCC 并共地。
> ⚠️ 本板 `5Vin` 实测 0V（见单颗测试），无法从板子取 5V。

## 编译 + 烧录（arduino-cli）

```powershell
arduino-cli compile --fqbn esp32:esp32:esp32s3 .
arduino-cli upload -p COM32 --fqbn esp32:esp32:esp32s3 .
```

## 测试内容（固件内）

1. **全亮单色**：红 → 绿 → 蓝 → 白（验证 16 颗都亮 + 颜色顺序）
2. **逐颗扫**：橙灯沿蛇形 0→15 依次点亮（验证灯序）
3. **追逐灯**：一颗沿蛇形来回跑
4. 熄灭后循环

## 预期现象（已实测 2026-08-28）

- 四色全亮阶段：16 颗应全部同色点亮 ✅
- 逐颗扫阶段：橙色灯从**右下角**开始，**沿右列向上**移动 ✅（每列从下往上爬）
- 3V3 供电：亮度 30 合适（80 偏亮）；16 颗满白约 200mA，勿再调高

## 测试结果

| 项 | 结果 |
|---|---|
| 16 颗全亮 + 颜色顺序 | ✅ 正常 |
| 灯序（右下角起，每列从下往上） | ✅ 与元件一致 |
| 3V3 供电亮度 30 | ✅ 合适；80 偏亮 |
| 元件灯序描述 | 已修正为“每列从下往上”（原假设为行/列交替蛇形，均与实测不符） |
