# 像素采集链：怎么实现（2026-10-15）

> 回答一个具体问题：**"数据采集"到底在哪一层实现、每一层做什么**。
> 相关文档：`pixel-netlist.md`（连线 ✓）／`README.md` §2 §4（架构与选型 ✓）／
> `bus-protocol.md` §4.4（回读时隙 ✓）／`coil-spec.md`（线圈 ✓）。

## 0. 一句话

**采集被拆成三层**：① 每块板上的**模拟前端**（已在 v0.1.1 的铜里 ✓）
② 每块 MCU 的**ADC 采样**（固件 ✗ 待写）③ 把读数**沿 3 线链回传**（协议在纸上 ✓，固件 ✗ 待写）。
这是 P1（每像素一块板）相对 P2（集中式）最大的变化：**ADC 从"集中一个 + 模拟开关扫描"变成"每块自带"** ✓。

## 1. ① 模拟前端 —— 已经在板上 ✓

```
L1 线圈(φ19/6匝, 顶层铜) → D3 BAS70BRW 全波桥 → BR+ → R1 10 kΩ → 节点 → U1.PD6 (ADC_IN6)
                                                              └→ C1 100 nF → GND
```

- **非谐振包络检测**：线圈直接进桥 ＋ RC 低通，**没有并联谐振电容** ✓（`README` §6.1 ✓）
  ⇒ 节点电压 ≈ 整流后的平均值 ∝ 线圈感应电压 ∝ 该处场强 ✓（显示的是**相对分布** ✓）
- **时间常数** `τ = R1·C1 = 10 kΩ × 100 nF = 1.0 ms` ⇒ 低通拐点 `f_c = 1/(2πτ) ≈ 160 Hz`
  ⇒ 包络稳定到 1% 约 **5τ = 5 ms** ⇒ 采样/刷新**最快 ~200 Hz**，再快没有意义 ✓
- **ADC 分辨率**（`Vref = VDD = 5 V`）：10-bit ⇒ LSB **≈ 4.9 mV**；12-bit ⇒ **≈ 1.2 mV**
  （`CH32V003F4U6` = 10-bit；`CH32V002F4U6` = 12-bit / 3 Msps，**同封装 drop-in** ✓ 用哪个等实测 ✓）
- ⚠️ 两个要注意的（都还没在板上解决 ✗）：
  1. **源阻抗 10 kΩ 偏高**：ADC 的采样电容要在采样窗内充满 ⇒ 采样窗要放长（先查手册的
     `RAIN` 上限 ✗），或在 ADC 脚再并一个小电容（如 1 nF）✓ —— 固件阶段实测 ✓
  2. **`Vref = VDD` ⇒ 5 V 轨的噪声就是测量噪声** ✗：板载 WS2812B 全白 60 mA、链上 I²R 压降
     都会落在 VDD 上 ⇒ 采样要**避开 LED 刷新的瞬间**（或先测 LED 关着时的值）＋ 去耦要够 ✓

## 2. ② 每块的采样（固件 ✗ 待写）

- 定时采（例如对齐到回读时隙，**100~200 Hz**）＋ 滑动平均/中值（把 160 Hz 以上的噪声压掉 ✓）
- **过采样换分辨率**：CH32V003 是 10-bit，用 **16× 过采样 + 抽取**可换回约 2 bit（⇒ 12-bit 等效 ✓），
  代价只是 CPU 时间（我们本来就很闲 ✓）—— 12-bit 的 V002 则直接有 ✓
- **单机模式**（`bus-protocol.md` §5 ✓）：收不到合法帧 ⇒ 自己用**局部归一化**点自己的 1010 ✓
- 基线：见 §4 ✓

## 3. ③ 回传到主控（协议已在纸上 ✓ `bus-protocol.md` §4.4）

- 主控广播 `[同步头][0x03][n]` ⇒ **`index == n` 的那一块**在随后的 k 个时隙里
  **开漏拉低自己的下游线**，一位一个时隙 ✓
- 中间节点只做 **"低脉冲接力"**：下游侧看到低 ⇒ 立刻把上游侧也拉低 ✓（**只传不造** ✗）
  ⇒ 主控在自己那根线上逐位读 ✓
- **预算**（按 §3 定的 800 kHz 位时钟 ✓）：每块 ≈ 32 bit 请求 ＋ 12 个时隙 ≈ **55 µs**
  ⇒ 64 块 ≈ **3.5 ms / 帧** ⇒ **~280 fps** ✓ —— 远超需要（包络本身只有 160 Hz 带宽 ✓）
- 颜色按 §4.3 的颜色帧下发：每块取走 3 B ✓（谁算颜色见 §5 ✓）

## 4. ④ 基线 / 背景：**P2 那套差分采样没了，要补回来** ✗

P2（集中式）用 **`TS3A44159`**：每通道在"信号"和"GND（背景）"之间切换 ⇒ 逐次**相减** ✓。
像素板上**没有这个开关** ✗（板上只有 L1/D3/R1/C1/C2/U1/LED2/J1/J2）⇒ **不能逐次差分** ✗。

三条替代（推荐 a ＋ b）：

| | 做法 | 代价 |
|---|---|---|
| **a** ✓ | **一次性标定**：无场环境下采一遍，把每块的基线写进 Flash（板上本来就要存 `index` ✓，多存 2 B ✓）| 需要一次"无场"标定工序 ✓ |
| **b** ✓ | **相对分布归一化**：显示的是相对分布 ⇒ 共同偏置/漂移会被抹掉（`README` §6.1 已论证 ✓）| 抹不掉**逐块**的差异 ✗ |
| **c** | **下一版（`v0.1.2`）加一处**：把一个备用 GPIO（如 `PD5`／`PD3`）从 RC 节点引出来，当**开漏"拉低/放电"**用 ⇒ 固件就能采"零基线" ✓ | 只多**一根线** ✓，不用加芯片 ✓ |

## 5. ⑤ 主控侧（ESP32-S3 控制板 —— `README` §8 待建 ✗）

- 职责：发**枚举帧**／**颜色帧**、收**回读**、算热力图（或直接把 64 个值映射成颜色）
- 它只占**链头**，**不参与**采集 ✓
- 单机模式下主控不在场 ⇒ 每块自己显示 ✓（同一套固件两种模式 ✓）

## 9. ★ 面包板第二轮改进测试（2026-11-10 拟定 ✓）

> 起因 ✓：§8 的 #7（储能）与 #6（DIN 阻尼）**在面包板上比在 PCB 上更重要** ✗
> ⇒ 先在台架把这两条验出来，**再决定要不要写进下一版 PCB** ✓（不在铜上赌 ✓）。

### 9.1 为什么面包板更需要（可算 ✓）

| 现象 | 面包板上的量 | PCB 上的量 |
|---|---|---|
| 5V 轨"软" | 弹片接触电阻 ~10–20 mΩ/点 ＋ 跳线 ~1 nH/mm（15 cm ⇒ ~150 nH ✗）| 8 mil 走线、无接触电阻 ✓ |
| 一颗 1010 全白 | **60 mA** 阶跃 ✓ | 同 ✓ |
| 只有 100 nF 时 | ΔV = I·Δt/C = 60 mA × 1 µs ÷ 100 nF ≈ **600 mV** ✗ | 同（离得近一点，稍好）|
| 加 10 µF | 同上 ≈ **6 mV** ✓ | ✓ |
| 加 47 µF | ≈ **1.3 mV** ✓✓ | ✓ |
| ⇒ 对 ADC 的影响 | `Vref = VDD` ⇒ 10-bit、5 V 下 **1 LSB = 4.88 mV** ⇒ 100 nF 一颗时跌落 ≈ **120 LSB 量级** ✗✗ | 同 ✓ |

★ 结论 ✓：**面包板上"灯珠闪一下"就是 ADC 读数跳几个百分点** ✓（不是两件事 ✓）；这正是 §8 #7 的实证机会 ✓。

### 9.2 加什么（面包板物料，**不改板** ✓）

| 位 | 加什么 | 放哪 |
|---|---|---|
| **A** | **47–100 µF / 10 V 电解** ＋ 已有的 **100 nF** | 电解跨在 LED 电源那一段的 **5V 轨–GND 轨**（用空闲孔 ✓，别占元件脚 ✓）；100 nF 尽量贴着灯珠 |
| **B** | **33–100 Ω（0805 或直插）串在 `PC6` → `LED2.DI`** 之间 | **靠 MCU 一侧** ✓（阻尼要靠近驱动端 ✓）|

★ 顺序（**一次一改** ✓）：先只加 **A** ⇒ 量一轮 ⇒ 再只加 **B** ⇒ 再量一轮 ✓（不然分不清是谁的功劳 ✗）。

### 9.3 量什么（判据写死，别"看着好像好点了" ✗）

| 项 | 怎么量 | 判据 |
|---|---|---|
| **1. 5V 轨跌落** | 示波器 AC 耦合、20 mV/div、夹面包板灯珠那段的 5V–GND；让灯珠**全白↔全黑**切换 | 加 A 后跌落峰值降 ≥ **5×** ✓ |
| **2. ADC 噪声** | 现有固件连续采 `PD6`（静止场、200 次）算 p-p 与 σ | 加 A 后 p-p 明显下降 ✓（`Vref=VDD` ⇒ 直接反映轨噪声 ✓）|
| **3. LED 误动作** | 800 kHz 连续刷 10 min（换色图案），计数错色/白闪/整条重启 | 加 B 后 **= 0** ✓；加 B 前若 > 0 ⇒ 问题复现 ✓ |
| **4. DIN 过冲** | 探头夹 `LED2.DI`，看上升沿过冲/振铃 | 串 B 后过冲 ≤ **5.5 V**（不超灯珠绝对最大）✓ 且振铃消失 ✓ |

### 9.4 结论怎么用 ✓

- 若 **A 有显著收益** ⇒ 下一版 PCB 加 **10 µF/10 V 0805**（§8 #7）✓；
- 若 **B 有显著收益** ⇒ 下一版 PCB 在 `PC6` 与灯珠之间预留 **0 Ω/22 Ω 焊位**（贴不贴都行 ✓）；
- 若两条都无收益 ⇒ **PCB 保持 v0.1.3 的料表** ✓（面包板上的补料留在台架 ✓，不进板 ✓）。
