## 4. 画图步骤（Fritzing GUI）

1. 新建 sketch → 保存为 `hardware/pixel/pixel.fzz`；
2. 切到**原理图**视图，从 MINE / core 拖入 §1 的元件（元件已同步进 MINE，搜型号即可）；
3. 排布（左 → 右）：`L1 → D1 / D2 → R1 / C1 → U1 → LED1`；`5V / GND / DATA` 三个网络标签放在 U1 两侧；
4. 按 §2 连线（Fritzing 会自动吸附到引脚端点）；
5. 保存后把 fzz 给我 —— 我读里面的 `wire` 元素**逐条核对网表**（和核对 single-channel 一样的方式）。

## 6. 备注

- BAT54S 方向按手册：`pin1 → pin3 → pin2`（`A1` → `node` → `K2`），两颗组成全波桥，**不能简单并联**；
- 整流输出 `BR+` 要 < VDD（场强过大时加钳位，见 README §3 的"过压钳位（可选）"）；
- 固件里 LED 时序用 SPI + DMA 产生（见 README §5.2 的 A2 方案）。
